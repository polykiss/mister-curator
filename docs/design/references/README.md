# Visual References

Inspiration images for MiSTerCurator's visual design direction.

These are inspiration, not specifications. The design pass should extract
principles (typography, palette, hierarchy, density, accent usage) — not
copy literally. The product is a desktop ROM curation tool, not a SaaS
dashboard, so directly applying any one of these would feel off.

Themes I'm drawn to across these:
- Dark, deep blacks and very dark muted grey with a ouch of blue
- Typography as the primary visual element
- Restrained color use — usually one accent against neutral
- Generous negative space
- Subtle borders rather than heavy fills
- Information hierarchy through size and weight
